# GitHub Pages Publishing Guide

1. Create a GitHub repository called `queenayodele`.
2. Set it to Public.
3. Upload `index.html` and the `assets` folder.
4. Go to Settings → Pages.
5. Source: Deploy from branch.
6. Branch: main.
7. Folder: /root.
8. Save.
9. In Custom domain, enter `queenayodele.com`.
10. Save.
11. After DNS works, enable Enforce HTTPS.
